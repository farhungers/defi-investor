## Thesis
BitMEX Research analyzes structural (not just supply-demand) factors that create persistent funding-rate divergence across venues in crypto perpetual futures markets.

## Key claims (from title)
- Rate gaps between venues aren't purely arbitrage-inefficiency; venue-specific structural features contribute.
- Structural factors likely include: contract specifications, oracle sourcing, index composition, clamp/cap behavior, liquidation mechanics.

## Relevance to defi-investor
Direct input to any confound involving funding rates. Also relevant if we ever revisit adding funding-rate divergence as a signal channel (Decision 5 menu wildcard that we declined). Cross-venue funding differentials might be a leading indicator of insider positioning — but scoping this is Phase 4+.
